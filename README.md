# PETMUNDO

Uma rede social para todos os pets!

## Nossa missão
Conectar tutores, animais, protetores e organizações de proteção animal.

## Animais
Cães, gatos, aves, répteis, peixes e todos os outros pets.

## Funcionalidades
- Perfis dos animais
- Publicações, fotos e vídeos
- Curtidas e comentários
- Comunidades
- Adoção responsável
- Aba permanente de DONATIVOS
- Campanhas de proteção animal

## Projeto
Brasil primeiro, com expansão internacional futura.
